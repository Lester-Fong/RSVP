# Floral trial asset provenance

The two SVG illustrations in this directory were authored for CMS-B.1a as **provisional original substitutes**. They do not contain extracted Figma paths, photographs or artwork. They preserve the floral/hero slots but are visibly different from the source. No model/customer photographs or personal credentials are used. Replace them only with rights-cleared assets before claiming final visual fidelity.

Unmodified fonts downloaded from the official Google Fonts repository on 2026-10-20:

- [Caladea Regular](https://github.com/google/fonts/tree/main/ofl/caladea): `fonts/caladea.ttf`, accompanying `caladea-OFL.txt`.
- [Dancing Script variable](https://github.com/google/fonts/tree/main/ofl/dancingscript): `fonts/dancingscript.ttf`, accompanying `dancingscript-OFL.txt`.
- [Roboto variable](https://github.com/google/fonts/tree/main/ofl/roboto): `fonts/roboto.ttf`, accompanying `roboto-OFL.txt`.

Each downloaded license explicitly permits redistribution under SIL OFL 1.1. Original file names: Caladea-Regular.ttf, DancingScript[wght].ttf, Roboto[wdth,wght].ttf. These match observed font families; exact Figma binary versions are unknown. Fonts are served locally by the isolated fixture, with no third-party runtime font requests. Total TTF payload about 704 kB; subsetting/WOFF2 production delivery remains future work.

Calendar/clock/location icons reuse the installed `lucide-vue-next` library (ISC). Rings/celebration outlines are original simple SVG drawings, not Figma exports. Source artwork/photograph rights remain unconfirmed; no temporary Figma asset URL is used at runtime. Source screenshots are inspection evidence only, never website assets.
