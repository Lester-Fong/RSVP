Horizon Minimal is an original project-specific adaptation inspired by the public `bryllim/bryl-minimal-design` repository by Bryl Lim.

The upstream project is MIT licensed.

This Horizon-specific specification changes the emphasis from portfolio/editorial layouts to operational application patterns such as management tables, CRUD modals, responsive navigation, permissions-aware screens, and church workflow usability.
